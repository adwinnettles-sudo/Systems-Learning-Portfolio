# Twitch VOD Cookie Authentication Investigation

A practical investigation documenting the troubleshooting process used to resolve authentication issues when downloading Twitch VODs.

Rather than assuming a network failure, this investigation focused on browser cookies, local authentication data, and application configuration.

---

## Purpose

Authentication issues can resemble network or application failures even when connectivity is functioning normally.

The goal of this investigation was to identify why authenticated downloads were failing and determine the underlying cause.
