# ChatGPT Connectivity Investigation

A practical investigation into a connectivity issue affecting access to ChatGPT through a web browser.

This repository documents the troubleshooting process used to distinguish between local network problems, DNS issues, browser behavior, and a remote server response.

---

## Purpose

A website failing to load does not automatically mean the internet connection is unavailable.

The goal of this investigation was to test each relevant part of the connection separately and determine how far communication was successfully progressing.
