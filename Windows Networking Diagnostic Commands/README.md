**Status:** Complete (v1.0)

**Difficulty:** Beginner

**Category:** Windows / Networking

---

## Overview

Windows includes several built-in utilities for diagnosing connectivity issues.

This repository documents the networking commands I've learned, when they're useful, and what I learned while using them.

Rather than serving as a complete command reference, the goal is to build practical intuition for troubleshooting Windows networking issues.

---

## Commands

| Command | Description |
|----------|-------------|
| ipconfig | View and manage local IP configuration |
| ping | Test basic connectivity |
| tracert | Trace network routes |
| nslookup | Query DNS servers |
| curl | Test HTTP responses |
