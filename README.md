Accuracy is prioritized over embellishment.

------------------------------------------------------------------------

# Learning Philosophy

I believe that understanding **why** a system behaves the way it does is
more valuable than memorizing commands or procedures.

When encountering an unfamiliar problem, my general workflow is:

1.  Observe the problem.
2.  Read the available error information.
3.  Consult relevant documentation or trusted technical resources.
4.  Form an initial hypothesis.
5.  Perform targeted diagnostics.
6.  Analyze the results.
7.  Refine my understanding.
8.  Document what I learned.

Over time, this process builds reusable mental models that apply across
different technologies.
