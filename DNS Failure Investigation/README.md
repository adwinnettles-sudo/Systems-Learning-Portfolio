# DNS Resolution Failure Investigation

A practical investigation documenting the process of diagnosing and understanding DNS resolution issues.

Rather than focusing solely on commands, this repository follows the reasoning process used to determine whether a connectivity problem originates from DNS or another part of the network.

---

## Purpose

DNS issues can appear similar to general internet connectivity problems, making them difficult to identify without a structured troubleshooting process.

The goal of this investigation is to demonstrate a logical approach to isolating DNS-related failures using standard networking tools.
